# Emotion Detection Lens 🎭

This project enables **real-time emotion detection** using Snap Spectacles, OpenAI’s GPT-4o, and custom visuals for emotion representation.

## 🔍 What It Does

- Captures live camera frames from Spectacles
- Sends image data to OpenAI for emotion analysis
- Displays top 3 predicted emotions with:
  - Labeled, colored spheres
  - Enlarged dominant emotion
  - Optional onboarding animation
